## 결과: 실패 (재개 단계)

- 첫 파드는 GPU(cuda)에서 2 에폭을 마쳤다. 삭제(SIGTERM)되자 `ckpt-e0003-s00001.pt`를 남기고 `INTERRUPTED`로 끝났다. 여기까지는 정상이다.
- 재시도 파드 5개는 모두 같은 오류로 실패했고, 재시도 한도 6회를 넘겨 Job이 Failed가 됐다: `TypeError: RNG state must be a torch.ByteTensor`
- 원인:
  - `train.py`가 체크포인트를 `torch.load(map_location=cuda)`로 읽었다. 그러면 데이터 생성기의 난수 상태(CPU 전용 ByteTensor)까지 GPU로 옮겨져, 이를 `set_state()`에 넘길 때 실패한다.
  - 로컬 검증은 CPU에서만 해서 드러나지 않았다.
- 조치:
  - 체크포인트를 CPU로 읽게 고쳤다(`map_location="cpu"`). 모델·옵티마이저 텐서는 `load_state_dict`가 GPU로 옮긴다.
