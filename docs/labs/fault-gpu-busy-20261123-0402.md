### 5.1 FAIL의 원인과 조치

- FAIL 항목: 4절 "GPU를 쓰는 파드가 남아 있지 않음"(04:03:36).
- **원인(스크립트 결함, 실험 결과의 이상이 아니다):** 스크립트가 `helm uninstall`(추론 릴리스 삭제) 직후 곧바로 `gpu_free`를 확인했다. 지워지는 파드는 종료 유예(Terminating) 동안 phase가 `Running`이라 `gpu_pods`가 그 파드를 GPU 사용 파드로 센다. 실험이 끝난 뒤 내가 확인한 시점(04:04경)에는 GPU를 요청한 파드가 0개였고, 뒤이은 점검(네임스페이스 삭제 PASS)도 같은 시각에 모두 통과했다.
- **조치:** `scripts/fault-test.sh`의 `run_gpu_busy`에서 확인 전에 `wait_for 60 gpu_free`로 종료 중인 파드가 사라지기를 기다린다. 같은 이유로 `verify_restored`(F1·F8의 `--gpu 1`)와 F2 끝에도 GPU 반납 확인을 넣었다. 3절의 "전환 구간 실패는 예상한 값이다" 문구도 실제 결과(이 실행은 실패 0)와 어긋나서 "예상이었고 실제 수는 위 지표"로 고쳤다. 자세한 줄은 `docs/labs/fault-week14-summary-20261123.md` 3절.
