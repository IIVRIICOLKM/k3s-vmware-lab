# 추론 워커 벤치마크 (2026-10-30 17:20)

- 생성: `scripts/infer-bench.sh resume-demo2 v0.1`
- 이미지 `registry.k3slab.local:5000/infer-worker:v0.1`, 모델: 학습 작업 `resume-demo2`의 `model.k3sm`
- WORK_MS는 배치 한 번당 고정 비용입니다. GPU 추론이 들어가기 전까지 GPU 호출 1회를 흉내 냅니다.

### MAX_BATCH=8

- 설정: 큐 500, 스레드 1, WORK_MS 20
- 요청 400개, 동시 100개

```text
    400 200
elapsed_seconds 1.31
k3slab_infer_queue_capacity 500
```
