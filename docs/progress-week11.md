## 이번 주 진행 항목

**Jenkins (10–12주) — 진행 중**

- 제안서 흐름: 코드가 올라오면 C++ 빌드와 Python 테스트를 돌리고, 통과했을 때만 이미지를 만들어 태그를 붙여 레지스트리에 올린다.
- 9주차 계획: C++ 빌드(`make CUDA=0`)와 Python 문법·단위 검사를 돌린 뒤, 지금과 같은 Kaniko 방식으로 이미지를 만든다.
- 결과 입력 대기:
  - 설치 위치, 자원(CPU·메모리·PVC), 버전
  - 파이프라인 단계와 정의 파일
  - 검사 실패 시 이미지가 만들어지지 않는 것을 보인 실행
  - 코드 push부터 이미지 push까지 걸린 시간

**Argo CD (11–13주) — 진행 중**

- 제안서 흐름: 배포 설정(YAML)의 이미지 태그만 바꾸면 Argo CD가 클러스터에 반영한다. 배포 설정과 실제 상태가 다르면 맞춘다.
- 결과 입력 대기:
  - 설치 위치, 자원, 버전
  - 배포 설정을 두는 Git 디렉터리
  - 태그 수정부터 반영까지 걸린 시간, 사람이 명령을 치지 않았다는 증거

**Prometheus·Grafana (12–14주) — 진행 중**

- 이미 준비된 것: 추론 워커가 `/metrics`로 큐 길이, 요청 결과(ok·rejected·timeout·bad_request·failed), 배치 크기, 계산 시간을 내보낸다.
- 결과 입력 대기:
  - 노드·파드, GPU, 추론 요청, 작업 상태 네 가지 관측 대상의 수집 방법과 대시보드 한 장
  - 모니터링이 쓰는 자원

**worker-cpu-1 메모리 점검 — 결과 입력 대기**

- 이 노드(6 GB)에는 지금 레지스트리(요청 64 Mi)와 MySQL(요청 512 Mi, 상한 1 Gi)이 있고, Jenkins·Argo CD·모니터링이 더해질 예정이다(`infra/k8s/registry.yaml`, `infra/k8s/mysql.yaml`).
- 실제 사용량은 클러스터를 켜고 잰 값으로 채운다.

**검증 실험 준비 (13–16주) — 진행 중**

- 9주차에 정한 방향: 물리 호스트가 하나라서 막을 수 없는 장애(GPU 고장, 디스크 고장 시 local-path 데이터 손실)와 막을 수 있는 장애(파드·노드 중단, DB 재시작)를 나눈다.
- 결과 입력 대기: 중단 상황 6종의 시험 절차와 기록 방식.

## 문제와 대응 (이번 주 발견)

1. **클러스터가 켜지지 않는다: VMware 커널 모듈이 없다.** (11/20 확인)
   - 커널이 7.0.0-43-generic으로 올라간 뒤 `vmmon`·`vmnet`이 로드돼 있지 않고, 이 커널용 `vmmon.ko`도 만들어져 있지 않다. 11/21에 `lsmod`와 `/lib/modules/7.0.0-43-generic`으로 다시 확인했다. 이전 커널(7.0.0-42 등)에는 모듈이 있다.
   - 11/20에 `scripts/entry.sh`를 돌렸을 때 `preflight.sh`가 FAIL을 냈고, Terraform의 전원 켜기가 `Failed to power on ... Transport (VMDB) error -32`로 실패했다. Terraform은 아무것도 바꾸지 않았다.
   - 10/1과 10/15에도 같은 증상이 있었다(커널 업데이트 때마다 모듈이 빠진다, `docs/progress-week08.md`).
   - 복구는 콘솔에서 `sudo vmware-modconfig --console --install-all`이다. sudo가 필요해서 사용자가 직접 해야 한다. (복구 결과 입력 대기)
2. **`entry.sh`가 Rocky ISO 확인 단계에서 멈춘다.** (11/20 확인)
   - 2/9단계 `fetch-rocky-iso.sh`가 `signed upstream SHA-256 is ''`로 멈춘다. 고정해 둔 Rocky 9.8 ISO가 공식 경로의 CHECKSUM에 더 이상 없다(9.9로 교체된 것으로 보인다).
   - 골든 이미지(`k3slab-golden-rocky98-20260918-1`)는 이미 있다. 이 단계는 확인만 하는데도 `entry.sh` 전체를 막는다.
   - 해결 방식(보관 경로로 확인할지, 골든 이미지가 있으면 건너뛸지)은 스크립트를 바꾸는 일이라 사용자 결정을 기다린다.
3. **영향**: 클러스터가 필요한 항목(Jenkins·Argo CD·모니터링 배포, 검증 실험, worker-cpu-1 메모리 실측)은 기동 전까지 실행할 수 없다. 클러스터 없이 할 수 있는 준비(매니페스트·스크립트·문서)부터 진행한다.
